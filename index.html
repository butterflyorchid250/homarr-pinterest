Personal Homelab Pinterest Integration

This is a private, self-hosted personal dashboard integration used by its owner to display the owner's Pinterest boards and Pins inside a private home dashboard.

The integration uses Pinterest's official OAuth and API interfaces.

Purpose

  • Display the owner's boards and Pins.
  • Show selected Pinterest content inside a private personal dashboard.
  • Provide convenient links back to Pinterest.

What it does not do

  • It does not create, edit, delete, or schedule Pins.
  • It does not run advertisements or provide services to other users.
  • It does not sell or share Pinterest data.

This project is for single-user personal use only.
