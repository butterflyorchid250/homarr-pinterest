Gmail Privacy Policy · Homarr Dashboard

Last updated: 13 October 2026

Who uses this application

Homarr Dashboard is a self-hosted personal application operated by its owner. Its Gmail features are intended solely for the owner to view and manage their own authorised Gmail account, not as a service for external users.

Google account access and data used

The application requests Gmail read, send and modify permissions through Google's OAuth 2.0 authorisation. It reads mailbox information including message identifiers, headers, message text or HTML, supported message images, label state and unread counts. It uses those data to display and operate the private email dashboard.

How data are used

Gmail data are used only to provide features requested by the owner: view inbox and message contents; compose, send or reply to messages; and mark messages read or unread, star or unstar, archive, or move them to Trash. The application does not automatically send, forward or permanently delete messages on the owner's behalf.

Storage and protection

OAuth credentials and refresh tokens are stored on the owner's private server in access-restricted files. Short-lived access tokens may also be stored server-side to make Gmail API requests. Message lists and selected message contents may be cached briefly in server memory for dashboard performance. The application renders email content in the authorised owner's private browser session. This public GitHub Pages website does not store account tokens or Gmail messages.

Sharing and third parties

The integration communicates with Google to authenticate and perform Gmail API operations. It does not sell, rent or share Gmail data with advertisers, data brokers or unrelated third parties. Email recipients receive messages only when the owner chooses to send them. External images in email may be fetched for display and are subject to the source website's handling of requests.

Advertising and analytics

The Gmail integration has no advertising or behavioural analytics features, and Gmail information is not used to train AI models.

Retention, control and revocation

The owner can revoke Google account access at any time through Google Account's third-party access settings. Gmail messages remain in the owner's Google account according to their Gmail settings and actions. To disconnect the private integration, the owner can revoke access and remove its server-side OAuth token. The short-lived application caches expire automatically.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adhere to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data are used only for the owner-facing functionality described above.
